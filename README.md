# Harris Tile Company — Website Demo

A polished static website concept for Harris Tile Company.

## Files

- `index.html` — full site
- `styles.css` — responsive layout, typography, animation and mobile styling
- `script.js` — navigation, reveal animation, gallery lightbox and demo form
- `assets/` — project imagery used in the concept

## Run locally

Just open `index.html` in a browser.

For the cleanest local preview, use VS Code + Live Server or any lightweight local server.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files and the `assets` folder to the repository root.
3. Commit and push.
4. In GitHub, go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save.
8. GitHub will provide the public Pages URL.

## Added interaction

- 3D scroll-built tile wall between Services and Project Gallery.
- Tiles begin scattered in 3D space and progressively settle into a finished wall as the visitor scrolls.
- Includes subtle camera movement, sheen animation, progress meter and responsive behavior.
- Built with CSS transforms + vanilla JavaScript; no framework required.

## Cinematic tile-to-project transition

The 3D tile build now continues into a finished-project reveal:

- 36 tiles assemble individually in perspective.
- The camera straightens as the grid completes.
- Grout gaps visually compress and tile depth flattens.
- The tile wall fades/morphs into a real Harris Tile bathroom image.
- Finished-project copy appears only after the reveal.
- The transition is scroll-driven and built with CSS transforms, clip-path, opacity, and vanilla JavaScript.
